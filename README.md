\# DataSphere

\### Universal Data Analytics \& Business Intelligence Platform



DataSphere is a Python-based data analytics platform developed using Streamlit. It provides an interactive environment for uploading, exploring, cleaning, filtering and analysing datasets through visual dashboards and statistical reports.



\## Key Features



\- Dataset Upload – Upload CSV and Excel files.

\- Data Overview – Explore dataset structure and statistical summaries.

\- Data Cleaning – Handle missing values, remove duplicates and manage columns.

\- Data Filtering – Filter datasets using selected conditions.

\- Analytics Dashboard – Generate interactive charts and visualisations.

\- Dashboard Templates – Explore predefined dashboard layouts.

\- Auto Dashboard – Automatically generate analytical visualisations.

\- Power BI Integration – Embed published Power BI reports.

\- Insights – Generate numerical, categorical and correlation insights.

\- Download Reports – Export datasets and reports in CSV, Excel, TXT and PDF formats.



\## Technology Stack



| Technology | Purpose |

\## Installation



1\. Clone the repository:



```bash

git clone https://github.com/gurneetkaurkohli/DataSphere.git

```



2\. Open the project:



```bash

cd DataSphere

```



3\. Create a virtual environment:



```bash

python -m venv .venv

```



4\. Activate it on Windows:



```powershell

.\\.venv\\Scripts\\Activate.ps1

```



5\. Install dependencies:



```bash

pip install -r requirements.txt

```



6\. Run the application:



```bash

streamlit run app.py

```
